# v1.3.1 稳定性设计

> 历史方案：KeychainFix 严格过滤已在真实使用中导致登录回归，v1.3.2 已撤回。
> 当前路由以 src/KeychainFix.m、README 和 CHANGELOG v1.3.2 为准，不再按本设计收窄。

用户已确认执行审查中的全部建议。本轮保留四个独立补丁及其现有效果。

- 构建独立于安装；KeychainFix 显式编译 vendored fishhook。
- SidebarPatch 保存并调用真实原方法；测试两个 UI 补丁双向加载顺序及禁用状态。
- KeychainFix 仅重定向带非空 service 的 generic-password、显式 DP 路由、精确访问组
  `3L68KQB4HG.com.readdle.PDFExpert-Mac` 的查询。未知查询透传；不读取用户凭据。
  该组来自已有排障证据，尚无服务名证据，不猜测服务名。
- 路径迁移保持依赖命令顺序/ordinal；重复补丁命令拒绝自动迁移，不重排。
- 注入器严格验证 Mach-O 边界、文件支持的 section、零填充和所有架构；
  所有修改先在内存完成，经临时文件原子替换，任何错误保持输入不变。
- 安装在副本完成注入/签名/验证后才提交；提交失败回滚 app 和共享 dylib。
  跨 app/dylib 的提交不是单一文件系统事务；串行锁和退出应用降低窗口风险。
- 完整官方原版备份按版本、构建号和主程序 SHA256 标识；恢复只接受匹配
  版本/构建的验证通过快照，不用旧单文件备份冒充完整签名恢复。
- 旧补丁安装可升级，但若没有完整官方快照，明确报告不能恢复官方签名。
- 验证使用合成二进制、替身 AppKit 类及安装测试副本；真实账号持久化留作
  用户交互验收。不自动提交 Git、不部署真实 app。
